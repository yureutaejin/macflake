# Agent Instructions

[CLAUDE.md](CLAUDE.md) is the canonical source of project guidance for all
coding agents. Read and follow it before working in this repository.

Also read and follow the rules it references:

- [.claude/rules/workflow.md](.claude/rules/workflow.md) for every task.
- Other Markdown rules under `.claude/rules/` when their `paths` frontmatter
  matches files involved in the task. Read applicable rules explicitly if
  your agent does not load them automatically.

Maintain shared guidance in `CLAUDE.md` and its rule files; keep this file as
an entry point rather than duplicating those instructions.
